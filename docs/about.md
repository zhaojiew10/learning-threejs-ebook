# 关于本书

## 内容说明

本电子书提供 **《Learning Three.js: The JavaScript 3D Library for WebGL, Second Edition》** 的中文内容。技术概念首次出现时采用“中文（English）”，后文以中文为主；API、类名、方法名、属性名、文件名和代码标识符保留英文。

## 阅读约定

- 代码、API、类名、属性、文件名和标准缩写保留英文形式。
- 文中 API 的拼写和行为按第二版保留，不会静默改写为其他版本。
- 书中的示例和外部链接具有对应版本的时代背景，实际使用时应注意当前环境差异。
